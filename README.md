# Calendar RL Fraternitatea

1. Creează un repository public `calendar-aniversari`.
2. Încarcă toate fișierele în rădăcina repository-ului.
3. Settings → Pages → Deploy from a branch → main → /(root).
4. Pagina publică: `https://UTILIZATOR.github.io/calendar-aniversari/`
5. Administrare: `https://UTILIZATOR.github.io/calendar-aniversari/admin.html`

După modificări în pagina de administrare, descarcă `data.json` și `aniversari.ics`, apoi înlocuiește fișierele cu același nume în GitHub.

Notă: GitHub Pages este static. Pentru salvare directă din iPhone, fără reîncărcare manuală pe GitHub, va fi nevoie ulterior de un backend securizat.
